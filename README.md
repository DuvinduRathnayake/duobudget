DuoBudget is a modern budgeting app designed to make money management simple, professional, and collaborative. Whether you’re budgeting solo or as a couple, DuoBudget helps you track income, expenses, and savings goals with clarity and ease.

⸻

✨ Features
	•	📊 Expense Tracking – Add and categorize expenses in real time.
	•	💰 Budget Planning – Set monthly budgets and spending limits across categories.
	•	👥 Designed for Two – Share and manage a joint budget effortlessly.
	•	🔔 Smart Reminders – Get notifications to update your daily expenses.
	•	🌙 Clean UI – Professional look with light/dark mode and smooth navigation.
	•	🔐 Secure Data – Local storage for privacy, with future cloud sync support.

⸻

🛠️ Tech Stack
	•	Frontend: React Native + Expo + Tailwind CSS (NativeWind)
	•	Navigation: Expo Router
	•	State Management: React hooks (useState, useEffect)
	•	Storage: AsyncStorage
	•	Backend (Planned): .NET / Node.js with REST API + SQL database
	•	Deployment: Expo + (planned) Azure hosting for backend

⸻
